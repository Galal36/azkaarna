# Azkaarna - Islamic Azkar App

Azkaarna is a high-performance, mobile-first Progressive Web App (PWA) designed for reading and counting daily Islamic Adhkar. Built with a focus on simplicity, speed, and offline resilience.

Live Site: [https://azkaarna.com](https://azkaarna.com)

## Features

1. Interactive Counters: Integrated digital tasbih for each dhikr with haptic feedback.
2. 100% Offline Support: Works anywhere via Service Workers (PWA).
3. Multi-Language: Supports Arabic, English, Urdu, and Indonesian.
4. Mobile-First Design: Optimized for thumb-reachability and centered on desktop.
5. High-Quality Typography: Uses authentic Amiri font for Arabic text.
6. Progress Persistence: Automatically saves your daily progress locally.

## Tech Stack

* Frontend: React 18, Vite
* Animations: Framer Motion
* PWA: Vite PWA Plugin
* Deployment: Nginx, Linux VPS, Let's Encrypt

## Getting Started

### Prerequisites

* Node.js (v18+)
* npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Galal36/azkaarna.git
   cd azkaarna
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
